# 市场环境与外部信息研究模块 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `quality_low_turnover_monthly_v1` 和 `low_vol_low_turnover_quality_v1` 补齐市场风格、板块轮动、外部市场、资金流、公告新闻和政策事件的研究诊断模块，先用于解释与归因，再决定是否进入策略构造。

**Architecture:** 采用“数据入库 -> 特征生成 -> 区间归因 -> 策略接入实验 -> 准入治理”的分层设计。外部信息第一阶段只作为诊断和风险覆盖，不直接成为主排序因子，避免新闻未来函数、文本延迟、主观标签和过拟合。

**Tech Stack:** Python 3.12+, pandas, SQLite/parquet, pytest, existing `phase0.walk_forward`, existing `phase0.external_market_history`, existing `phase0.intelligence`, Tushare data workflow, reports registry/path conventions.

---

## 背景判断

最近一次准入显示，两条质量低换手策略的核心失败不是平均收益、换手、回撤、财务数据覆盖或复权价格口径，而是：

- 第一个样本外区间 `2024-04-01` 至 `2025-03-31` 小亏。
- 第二个样本外区间 `2025-04-01` 至 `2026-03-31` 明显盈利。
- 两个样本外区间只有一个赚钱，赚钱区间占比为一半，无法达到准入标准。
- 行业集中审计触发失败，说明组合可能暴露在少数行业或阶段性市场风格上。

因此，下一步不应先放宽准入标准，也不应直接增加新闻或政策交易信号。更稳妥的研发路径是先补齐市场环境诊断模块，证明亏损区间到底是否由市场风格切换、板块轮动、外部市场压力、资金流偏好或事件冲击造成。

## 当前已有基础

- 已有跨市场行情数据模块：`phase0/external_market_history.py`。
- 已有跨市场特征生成入口：`phase0/walk_forward.py` 中的跨市场分数、风险状态和仓位缩放。
- 已有新闻与情报方向任务文档：`docs/tasks/data-sources/NEWS_SOURCE_IMPLEMENTATION_TASKS.md`、`docs/tasks/research/STRATEGY_INTELLIGENCE_WORKFLOW_TASKS.md`。
- 已有情报采集基础包：`phase0/intelligence/__init__.py`。
- 已有 Tushare 技能与数据方向，可覆盖 A 股指数、行业板块、资金流、公告新闻、政策和宏观数据。
- 两条目标策略目前配置中未启用跨市场风险覆盖，新闻、政策、宏观和资金流也未参与选股、仓位或准入判断。

## 总体边界

纳入范围：

- 市场风格诊断：大小盘、成长价值、质量低波、红利周期、主题成长等阶段性风格。
- 板块轮动诊断：行业或主题指数的相对强弱、持续性和策略持仓暴露。
- 外部市场诊断：美股科技、港股互联网、波动率、汇率等已存在跨市场数据。
- 资金流诊断：北向、主力、行业资金流、成交活跃度。
- 文本事件诊断：公告、研报、新闻、政策事件，只做解释和事件时间线。
- 策略归因报告：解释两个样本外区间为什么表现不同。

暂不纳入范围：

- 不把新闻标题、政策摘要或大模型判断直接作为买卖信号。
- 不在未完成时点有效性验证前把文本事件放进回测。
- 不一次性重写回测引擎。
- 不为了通过准入而放宽现有门槛。
- 不引入无法稳定复现、无法授权使用或无法审计来源的数据。

## 模块设计

### 模块一：市场环境数据层

职责：

- 拉取并缓存 A 股主要指数、风格指数、行业指数、主题指数、宏观序列、资金流和外部市场行情。
- 统一日期、来源、抓取时间和可见时间。
- 输出可复用的本地研究表。

建议新增或扩展文件：

- Create: `phase0/market_regime_data.py`
- Create: `tests/test_market_regime_data.py`
- Modify: `config.yaml`

第一版数据范围：

- A 股宽基：沪深 300、中证 500、中证 1000、创业板指、科创 50。
- 风格代理：大盘、小盘、成长、价值、红利、低波、质量。
- 行业与主题：申万行业、同花顺或东方财富主题指数，先选一种口径。
- 资金流：北向资金、行业资金流、市场成交额。
- 外部市场：沿用已有美股科技、港股互联网、波动率、汇率数据。

验收标准：

- [ ] 能按日期区间生成统一市场环境原始数据表。
- [ ] 每条数据保留来源、抓取时间和可见时间。
- [ ] 缺失数据不会静默填充为有效信号。
- [ ] 输出覆盖率报告，说明哪些数据可用、哪些缺失、哪些需要权限。

### 模块二：市场风格与板块轮动特征层

职责：

- 把原始市场数据转成可解释的市场环境特征。
- 特征先服务诊断，不直接进入交易信号。

建议新增文件：

- Create: `phase0/market_regime_features.py`
- Create: `tests/test_market_regime_features.py`

第一版特征：

- 市场趋势：宽基指数二十日、六十日收益。
- 市场宽度：上涨股票占比、创新高占比、强势行业数量。
- 风格强弱：小盘相对大盘、成长相对价值、低波相对高波、红利相对成长。
- 板块轮动：行业指数相对宽基收益、行业强度排名、行业动量持续性。
- 风险状态：波动率抬升、汇率压力、外部科技股压力、港股互联网压力。
- 资金偏好：北向净流入、行业资金净流入、成交活跃度。

验收标准：

- [ ] 所有特征使用当日或之前可见数据。
- [ ] 特征表按交易日输出，能与回测交易日对齐。
- [ ] 特征缺失时明确标记，不参与结论计算。
- [ ] 单元测试覆盖趋势、相对强弱、缺失值和时点右移规则。

### 模块三：双区间表现归因报告

职责：

- 对比 `2024-04-01` 至 `2025-03-31` 和 `2025-04-01` 至 `2026-03-31` 两个样本外区间。
- 判断两条策略的表现差异是否与市场环境相关。

建议新增文件：

- Create: `phase0/strategy_regime_attribution.py`
- Create: `tests/test_strategy_regime_attribution.py`

报告输出：

- `reports/runs/<日期>/<运行编号>__strategy_regime_attribution__quality_low_turnover_dual/strategy_regime_attribution__report.md`
- `strategy_regime_attribution__factor_by_period.csv`
- `strategy_regime_attribution__industry_exposure.csv`
- `strategy_regime_attribution__event_timeline.csv`

归因维度：

- 策略收益与市场风格收益对比。
- 策略持仓行业暴露与行业轮动对比。
- 策略持仓风格暴露与市场风格对比。
- 风险状态期间的仓位、回撤和换手。
- 重大公告、新闻、政策事件只做时间线解释，不做收益归因断言。

验收标准：

- [ ] 能解释两个样本外区间的市场环境差异。
- [ ] 能说明亏损区间是否存在行业集中或风格逆风。
- [ ] 能输出“已证明”“弱相关”“无法证明”的结论等级。
- [ ] 报告不把相关性描述成确定因果。

## 决策门槛

研究阶段通过：

- [ ] 双区间归因报告能稳定复现。
- [ ] 数据覆盖率和时点有效性可审计。
- [ ] 外部环境解释与策略表现存在可复查证据。

实验阶段通过：

- [ ] 风险覆盖或行业轮动接入后，弱区间表现改善。
- [ ] 年化换手仍低于准入上限。
- [ ] 最大回撤不恶化。
- [ ] 多窗口样本外表现优于基线。

准入候选通过：

- [ ] 赚钱样本外区间占比达到当前准入标准。
- [ ] 行业集中失败数归零或显著下降。
- [ ] 过拟合风险不高于中等。
- [ ] 外部数据源、字段、可见时间和缺失处理全部可追溯。

## 风险与取舍

- 市场风格和新闻政策解释很容易事后归因，必须先做时点有效性和样本外验证。
- 板块轮动信号可能提高换手，与低换手策略目标冲突，优先作为约束和风险覆盖。
- 新闻和政策数据存在授权、延迟、缺失和主观解读风险，第一阶段只做解释层。
- 外部市场信号可能对 A 股质量低换手策略解释力有限，应以证据决定是否继续投入。
- 如果归因报告无法证明市场环境解释有效，应回到组合构造、行业约束和因子稳定性修正。

## 最小可验证路径

最小版本只做三件事：

1. 用现有跨市场数据和 Tushare 可用市场数据生成每日市场环境特征。
2. 对两个样本外区间生成市场风格、行业轮动和策略暴露对比报告。
3. 判断是否值得进入风险覆盖或行业轮动接入实验。

如果最小版本不能解释弱区间亏损，就停止外部信息接入，回到质量低换手策略本身的行业分散和持仓构造修正。
