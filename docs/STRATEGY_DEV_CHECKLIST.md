## 2. 立项前判断

- [ ] 这是不是 **A股本土主因子**，而不是跨市场主 ranker
- [ ] 这套策略是否能只靠当前 Phase 0 数据落地
- [ ] 若需要额外数据，是否已有明确接入路径
- [ ] 预期输出是 **候选池 / 排名 / 风险缩放 / 开平仓规则** 中的哪一种
- [ ] 是否符合项目当前主线：**本土主因子选股 + 跨市场 overlay 解释/缩放**

不满足上面 3 项以上时：
- [ ] 暂不进入 Phase 0 主实验
- [ ] 仅保留为 `later / research-only`

---

## 4. 策略定义

### 4.1 信号层

- [ ] 明确使用哪些核心因子/特征
- [ ] 每个因子是否可解释
- [ ] 因子方向是否明确（越大越好 / 越小越好）
- [ ] 因子是否需要标准化
- [ ] 因子是否需要去极值
- [ ] 因子是否需要中性化（行业/市值）

### 4.2 组合层

- [ ] 选股方式：`top_n / 分位数 / 阈值触发`
- [ ] 调仓频率：`日 / 周 / 月`
- [ ] 权重方式：`等权 / 分数加权 / 风险缩放`
- [ ] 是否允许空仓
- [ ] 是否允许做空（Phase 0 默认否）

### 4.3 风控层

- [ ] 单票权重上限
- [ ] 单行业权重上限
- [ ] 波动率过滤
- [ ] 最大回撤熔断
- [ ] 流动性过滤
- [ ] ST/停牌/新股过滤

---

## 5. 回测设计

- [ ] 训练窗口长度明确
- [ ] 验证窗口长度明确
- [ ] 是否 walk-forward
- [ ] 是否样本内/样本外分离
- [ ] 是否和当前 baseline 对比
- [ ] baseline 是否至少包含：
  - [ ] `legacy_momentum`
  - [ ] 当前启用策略
  - [ ] 等权持有/指数基准

### 5.1 Phase 0 默认交易参数

- [ ] 初始资金：`1,000,000`
- [ ] 佣金：`0.00025`
- [ ] 卖出印花税：`0.0005`
- [ ] 基础研究滑点：`0.001`
- [ ] 主测试滑点：`0.00246`
- [ ] 压力测试滑点：`0.003` / `0.005`
- [ ] 最小样本数：`200`

## 7. Effectiveness Gate

进入候选保留的最低要求：

- [ ] `annualized_return_mean > 0`
- [ ] `sharpe_mean > 0.5`
- [ ] `max_drawdown_mean > -0.25`
- [ ] `win_rate_mean > 0.45`
- [ ] `oos_return_decay_ratio < 0.30`

若不满足：

- [ ] 标记为 fail
- [ ] 写清失败原因：`收益不够 / 回撤过大 / 换手过高 / OOS 崩塌`
- [ ] 给出下一步调整方向

## 9. 复现优先级参考

### 9.1 可优先照着做

- [ ] 多因子 + SVM 选股
- [ ] 多因子 + 量价增强
- [ ] 高维特征直接映射权重
- [ ] 均线 + K线规则基线
- [ ] 网络因子扩展（前提是行业/关联结构数据准备好）

### 9.2 暂不建议直接做主策略

- [ ] 跨市场映射直接做主 ranker
- [ ] 需要融资融券约束的双边策略
