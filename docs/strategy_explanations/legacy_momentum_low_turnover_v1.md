# Legacy Momentum Low Turnover V1（低换手经典动量）

## 核心概念

`legacy_momentum_low_turnover_v1` 是当前项目的主候选。它不是换掉动量逻辑，而是把原本过于频繁的经典动量，改造成更克制、更接近真实执行的版本。

核心思想是：买入时严格一点，持有时宽容一点，减少来回换股。

## 实际做法

代码中的真实行为如下：

- 动量窗口在 `mom5` 和 `mom20` 中选
- 买入使用较高阈值 `buy_threshold`
- 持有使用较低阈值 `hold_threshold`
- 新买时只看前 `buy_top_n`
- 已持有的股票只要没跌出更宽的 `hold_top_n`，就继续拿着
- 调仓不是每天做，而是按 `rebalance_days` 周期执行
- 还要求最少持有 `min_hold_days`
- 训练选参时直接惩罚高换手 `turnover_penalty`
- 权重仍然是等权基础上叠加 `vol20` 缩仓
- 信号收盘后生成，下一交易日执行
- 交易成本完整扣除

## 名称解释

这里的 `low_turnover` 不是描述性的口号，而是代码里真实存在的四类约束：

1. 买入阈值和持有阈值分离  
2. 新买排名范围和持有排名范围分离  
3. 周期性调仓  
4. 训练阶段惩罚高换手

## 关键特点

- 仍然属于动量策略，不是价值策略
- 仍然追强，但不再“见弱就马上扔”
- 重点优化的是执行方式，而不是因子种类
- 目标是把被交易摩擦吃掉的收益留住

## 当前结果

这是当前唯一正式通过 Phase 0 gate 的候选。

- `annualized_return_mean = 0.1440`
- `sharpe_mean = 1.0886`
- `max_drawdown_mean = -0.1012`
- `win_rate_mean = 0.5129`
- `turnover_annual_mean = 1.50`

它当前胜出的原因，不是用了更复杂的信号，而是把原本的动量策略做得更稳、更省换手。
