# Core Selection Quality Momentum V1（核心选股质量动量）

## 核心概念

`core_selection_quality_momentum_v1` 是面向“核心选股策略”定义的一版候选。它不追求行业押注，而是试图在同一股票池里找出财务质量较好、相对强势、波动不过高的股票。

它的目标不是去回答“哪个赛道最强”，而是回答“在控制风格噪音之后，能不能稳定选出更好的股票”。

## 实际做法

代码中的真实行为如下：

- 先生成两类核心特征：
  - `quality_growth_score`
  - `resid_mom`
- 只有同时满足以下条件的股票才进入候选：
  - `quality_growth_score >= quality_threshold`
  - `resid_mom > residual_threshold`
  - `close > ma(trend_window)`
  - `vol20 <= vol_threshold`
- 排名分数不是单一因子，而是三部分组合：
  - `0.55 * 质量成长`
  - `0.25 * 残差动量`
  - `0.20 * 低波动`
- 再按横截面排名取前 `top_n`
- 持仓仍然使用等权基础上叠加 `vol20` 缩仓
- 默认不依赖跨市场 overlay，但可以打开

## 名称解释

- `Core Selection`：强调它属于核心选股策略，而不是主题暴露策略
- `Quality`：强调公司质量和成长性
- `Momentum`：强调价格和相对强势仍然参与排序

这个名字代表的不是“因子越多越好”，而是“尽量把个股选择能力和赛道押注拆开”。

## 关键特点

- 更适合作为主线候选的对照实验
- 相比纯动量，更重视公司质量
- 相比主题暴露，更克制行业倾斜
- 如果行业约束接上，它会比主题策略更接近真正的横截面选股

## 当前定位

它目前只是策略积木中的新候选，默认还没有启用，不进入当前正式 compare 主线。

更准确地说，它现在承担的是一个方法论角色：

> 如果我们希望主策略证明自己不是单纯靠行业轮动赚钱，就需要有一类像它这样的“核心选股型”候选来做对照。
