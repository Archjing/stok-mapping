# Theme Exposure Momentum V1（主题暴露动量）

## 核心概念

`theme_exposure_momentum_v1` 是面向“行业 / 主题暴露策略”定义的一版候选。它不是刻意回避集中，而是允许收益更多来自强势主题、强势行业和跨市场风险偏好的同向共振。

它要回答的问题不是“能否公平地挑出更好的股票”，而是“在主题行情里，能否更高效地跟上最强方向”。

## 实际做法

代码中的真实行为如下：

- 主要信号来自价格趋势和中短期动量：
  - `mom(mom_window) > mom_threshold`
  - `close > ma(trend_window)`
- 同时要求：
  - `vol20 <= vol_threshold`
  - `amount_ratio20 >= amount_ratio_min`
  - 某些配置下必须 `breakout20 > 0`
- 如果开启跨市场 overlay，还会要求：
  - `mapped_xmarket_score >= xmarket_threshold`
- 排名分数以主题趋势为主：
  - `0.75 * 动量排名`
  - `0.25 * 跨市场映射排名`
- 再取前 `top_n`
- 组合层仍然使用等权 + 波动率缩仓

## 名称解释

- `Theme Exposure`：强调这类策略允许收益来自主题和行业暴露
- `Momentum`：说明它本质仍然是趋势跟随，不是价值策略

这个名字的重点不是“主题”两个字好听，而是明确承认：

> 这类策略的收益来源里，本来就可能包含行业集中和风格押注。

## 关键特点

- 比核心选股策略更容易集中到热门主题
- 更适合做顺势、赛道和风险偏好共振行情
- 对风格切换更敏感
- 不能和“核心选股策略”用同一把尺子直接解释

## 当前定位

它目前也是新加的策略积木，默认还没有启用，不进入当前正式 compare 主线。

它存在的意义主要是做分类和对照：

- 如果它明显跑赢核心选股策略，说明收益更可能来自主题暴露
- 如果核心选股策略更稳，说明主线更适合走“约束行业集中”的方向
