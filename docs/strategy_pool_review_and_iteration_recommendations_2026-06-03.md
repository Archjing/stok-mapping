## 1. 执行结论

当前策略池已经从“能否跑出正收益”进入“是否能稳健转入长期观察”的阶段。最新 Phase 0 walk-forward 中，唯一值得保留为主策略的是 `legacy_momentum_low_turnover_v1`：

| 指标 | 当前值 |
| --- | ---: |
| `annualized_return_mean` | `0.1121` |
| `sharpe_mean` | `0.8204` |
| `max_drawdown_mean` | `-0.1110` |
| `win_rate_mean` | `0.5000` |
| `turnover_annual_mean` | `1.49` |
| `positive_fold_ratio` | `0.75` |
| `min_fold_annualized_return` | `-0.1117` |

但当前策略池的结构仍然偏窄：主策略本质仍是动量策略，只是通过低换手、持有缓冲、最小持有期、换手惩罚和波动率缩仓把执行摩擦压了下来。它已经吸收了 A 股报告中“低换手”“低波控制”的一部分思想，但还没有真正落地“低波 + 低换手 + 高质量”的核心组合，也缺少系统的因子有效性筛选、收益来源拆解和过拟合诊断。

下一轮研发不建议继续在动量、K 线和量价过滤上叠更多条件。更优方向是：

1. 建立 `low_vol_low_turnover_quality_v1`，作为当前主策略的第一替代候选。
2. 把 `legacy_momentum_low_turnover_v1` 从“主 ranker”降为“动量 sleeve / 价格确认层”的可组合模块。
3. 对现有失败候选做减法，保留思路，不保留当前参数形态。
4. 先做因子 IC / 分组收益 / 成本敏感性 / 参数稳定性诊断，再上 SVM、XGBoost 或深度模型。

## 2. 文献与项目依据

### 2.1 A 股有效策略报告给出的方向

`A股有效量化策略报告.md` 的核心判断是：

- A 股低波因子稳定性最高。
- 小市值长期有效但近年减弱，需要谨慎处理。
- 质量因子，尤其 ROE、现金流质量、成长性和低杠杆，近年有效性增强。
- A 股动量存在特殊性：短期反转显著，中期动量有效，直接短线追涨容易被噪声和成本侵蚀。
- 低换手率因子在 A 股中极强，高换手股票往往对应高估和未来低收益。
- 推荐组合是低波、低换手、高质量，再少量叠加短期反转和公告事件。

这和当前项目结果高度一致：真正跑出来的不是“更激进的动量”，而是“降低换手后的动量”。但项目还缺少质量因子和低换手因子作为独立 alpha 来源。

### 2.2 中文文献给出的可落地启发

`cn05_ml_asset_characteristics_portfolio.md` 的重要启发不是“马上上深度学习”，而是：资产特征可以直接服务组合权重，交易摩擦类特征在中国市场非常重要。这支持项目继续把换手、流动性、波动率、交易成本约束前置，而不是只优化预测准确率。

`cn03_svm_multifactor_hs300.md` 给出一个标准多因子流程：先做因子暴露、相关性、IC 筛选，再用市值、股本、换手率、ROE、PE 等有效因子进入 SVM。对当前项目的直接启发是：机器学习之前必须先把因子有效性和冗余关系跑清楚。

`cn09_svm_price_volume_cs1000.md` 说明量价数据可以作为多因子后的二次筛选，但它不是替代基本面和低波低换手的主逻辑。当前项目的 `multifactor_volume_price_filter_v1` 失败，说明“量价过滤 + 多条件叠加”如果不控制换手和样本外稳定性，会被成本吞噬。

`cn07_lasso_pricing_factors_china.md` 的启发是因子动物园风险：高维因子需要筛掉冗余和无效因子。当前项目已经有多个候选策略，但缺少一层“因子是否真的有边际贡献”的诊断工具。

## 3. 当前策略池逐项评估

### 3.1 `legacy_momentum_low_turnover_v1`

状态：保留为当前主策略，但不得视为最终答案。

优点：

- 是当前唯一通过 Phase 0 的候选。
- 年化换手约 `1.49`，明显优于旧 `legacy_momentum` 的高换手形态。
- 最大回撤控制较好，均值约 `-0.1110`。
- 参数选择体现了实盘约束：买入阈值、持有阈值、持有排名缓冲、周期调仓、最小持有期和换手惩罚。
- 与 A 股低换手、低波控制方向一致。

问题：

- 本质仍是动量策略，核心信号只在 `mom5` / `mom20` 中选择。
- 第一折为负，`annualized_return = -0.1117`，说明至少有一种市场状态下该策略会失效。
- 最新 OOS 只有 1 折，不能过度解读 `oos_return_decay_ratio = -4.6042`。
- 缺少独立质量因子、估值因子、低换手率因子和公告事件因子。
- 当前成功可能更多来自交易节奏优化，而不是 alpha 来源升级。

建议：

- 继续作为 selected candidate 进入观察池和模拟账户。
- 增加风格暴露报告：市值、波动率、换手率、行业、动量暴露。
- 接入 T2.4 过拟合诊断，重点检查参数邻域稳定性和收益集中度。
- 下一步把它拆成“动量 sleeve”，用于和质量/低波/低换手主因子组合。

### 3.2 `legacy_momentum`

状态：只保留为 baseline。

当前结果已经转负：`annualized_return_mean = -0.0536`，`sharpe_mean = -0.5634`，`turnover_annual_mean = 13.33`。

它的价值不在于继续优化，而在于作为对照组证明：单纯短线追强在当前成本口径下不可取。后续不建议继续直接调它的参数。

### 3.3 `quality_growth_price_v1`

状态：保留方向，重做形态。

这是当前候选里最接近 A 股报告推荐方向的策略，但当前结果较差：`annualized_return_mean = -0.1173`，`sharpe_mean = -1.4395`，`turnover_annual_mean = 24.89`。

主要问题不是“质量因子无效”，而是当前实现把质量、趋势和调仓节奏组合得太交易化：

- 财务质量是慢变量，不适合高换手日频筛选。
- `quality_threshold + close > ma + vol20` 的组合可能把慢因子变成了短线择时。
- 财务因子虽然已经做 PTI 校验，但仍需要按公告日、报告期和可得性分层评估。

建议：

- 将该策略改造成月频或 20 日以上调仓。
- 先做纯质量分组收益和 IC，不直接叠趋势。
- 分拆质量字段贡献：ROE、现金流质量、利润增长、营收增长、低负债。
- 与低波、低换手率合成，不再单独追求价格趋势过滤。

### 3.4 `multifactor_volume_price_filter_v1`

状态：当前版本淘汰，保留“多因子 + 量价二次筛选”的研究方向。

当前结果：`annualized_return_mean = -0.2528`，`sharpe_mean = -2.1113`，`turnover_annual_mean = 49.40`。

该策略的问题很典型：结构看起来完整，但过滤条件过多、参数维度过高、换手太高，导致真实成本下 alpha 无法留下。它对应了个人量化里常见的“把多个看似合理的条件叠起来，回测复杂度提高但样本外更差”。

建议：

- 不继续在当前版本上加过滤。
- 改为两阶段实验：
  1. 第一阶段：低波、低换手、质量、估值、动量分别做 IC / 分组收益。
  2. 第二阶段：只对通过第一阶段的 3-5 个因子做线性打分或 SVM 二次筛选。
- 增加换手上限和月频/双周频约束，不能继续用高频条件驱动组合。

### 3.5 `residual_momentum_reversal_v1`

状态：研究方向保留，当前版本不保留。

当前结果：`annualized_return_mean = -0.2593`，`sharpe_mean = -2.4780`，`turnover_annual_mean = 29.22`。

残差动量 + 短期反转在 A 股逻辑上是合理的，但当前版本没有跑出来。可能原因：

- 残差动量窗口和反转窗口过短，信号噪声高。
- 反转条件没有变成“避开短期过热”的缓冲，而是变成频繁交易触发器。
- 跨市场 overlay 对主 ranker 贡献有限，可能增加了复杂度。

建议：

- 改为动量主策略的风险过滤层，而不是独立选股策略。
- 使用 20-60 日中期动量，叠加 3-5 日短期反转排除近期过热标的。
- 引入低换手持有机制，禁止日频快速换股。

### 3.6 `residual_momentum_reversal_v2`

状态：淘汰当前版本。

当前结果：`annualized_return_mean = -0.3676`，`sharpe_mean = -3.1566`，`turnover_annual_mean = 65.22`。

V2 加了成交质量和形态质量过滤，但结果比 V1 更差。这说明增加过滤项没有解决核心问题，反而提高了参数复杂度和换手。

建议：

- 不再作为独立候选参与 compare。
- 若保留，只作为研究样本，用于验证“复杂过滤项是否增加过拟合风险”。

### 3.7 `ma_kline_baseline_v1`

状态：只保留为技术基线。

当前结果：`annualized_return_mean = -0.4203`，`sharpe_mean = -3.5391`，`max_drawdown_mean = -0.4512`，`turnover_annual_mean = 40.44`。

均线/K线策略在文献里可作为简单规则参考，但在当前项目股票池、成本和调仓口径下明显不成立。

建议：

- 不作为生产候选。
- 继续用于 sanity check：如果某个复杂策略跑不过它，说明复杂策略没有意义。
- 不再投入研发资源调参。

## 4. 策略池结构性问题

### 4.1 当前候选过度偏价格行为

7 个候选里，大多数围绕动量、残差动量、均线、K 线、量价形态展开。真正符合 A 股报告核心组合的“低波 + 低换手 + 高质量”只有局部落地：

- 低波：多数策略有 `vol20` 缩仓或过滤，但它更多是风险控制，不是独立 alpha 因子。
- 低换手：只有主策略显式成功落地。
- 高质量：已有 `quality_growth_price_v1`，但交易节奏和组合方式不合适。
- 短期反转：已有 residual reversal，但没有和低换手机制结合。
- 公告事件：尚未进入策略池。

### 4.2 失败策略共同特征是高换手

失败候选的年化换手大致在 `24.89` 到 `65.22` 之间。当前主测试滑点为 `0.00246`，再加佣金和印花税，高换手策略很难留下正 alpha。

这说明下一步研发的第一硬约束应该是：

> 新候选年化换手必须先控制在 `<= 3`，否则除非有极强样本外证据，不进入主线。

### 4.3 现有 gate 还不足以识别过拟合

当前 gate 能检查收益、夏普、回撤、胜率和 OOS 衰减，但还不能回答：

- 参数邻域是否稳定
- 收益是否集中在少数股票或少数交易
- 因子是否有稳定 IC
- 是否只是候选池里偶然跑出来的 winner
- 样本外折数是否足够

因此 T2.4 策略过拟合诊断工具是必要的，不应只作为附属文档存在。

## 5. 下一步研发建议

### 5.1 P0：新增低波低换手质量三因子候选

建议新增：

```text
low_vol_low_turnover_quality_v1
```

定位：

- 当前主策略的第一替代候选。
- 不以动量为主 ranker，而以低波、低换手和质量作为核心。

候选因子：

- `low_volatility`: `-vol20` 或 `-vol60`
- `low_turnover`: 低成交活跃度 / 低换手代理
- `quality`: ROE、现金流质量、利润增长、营收增长、低负债
- 可选：估值安全边际，如 PE / EP
- 可选：轻量价格确认，如 `close > ma60`

初始组合方式：

```text
score = 0.40 * low_vol_rank
      + 0.25 * low_turnover_rank
      + 0.25 * quality_rank
      + 0.10 * medium_momentum_rank
```

约束：

- 调仓周期：20 个交易日或月频。
- 年化换手目标：`<= 3`。
- top_n：优先 `10 / 20`，不要只选 `3 / 5`。
- 信号收盘后生成，下一交易日执行。
- 必须通过 `research` 和 `live` profile。

验收：

- 年化收益为正。
- Sharpe > `0.5`。
- 最大回撤 > `-0.25`。
- 年化换手 <= `3`。
- 不允许只靠最后一折拉高。
- 分组收益要显示低波/低换手/质量至少有一个稳定贡献。

### 5.2 P0：先做因子诊断，再做模型

在新增复杂策略前，建议先建因子诊断报告：

```text
reports/factor_effectiveness_report.md
reports/factor_effectiveness.csv
```

至少覆盖：

- 因子覆盖率
- 缺失率
- 分位数组合收益
- Rank IC / ICIR
- 年度 IC
- 多因子相关矩阵
- 因子换手
- 成本后分组收益

优先诊断的因子：

- `vol20`
- `vol60`
- `amount_ratio20` 或换手代理
- `mom20`
- `mom60`
- `mom3` / `mom5` 反转
- `roe`
- `cash_flow_quality`
- `profit_growth`
- `revenue_growth`
- `low_debt`
- `pe` / `ep`，若字段可得

这一步对应 `cn03` 的因子暴露、相关性、IC 流程，也对应 `cn07` 的因子冗余风险。

### 5.3 P1：把主策略模块化为 sleeve 组合

当前主策略不应被丢弃，但应从“唯一主策略”升级为组合中的一个 sleeve：

```text
portfolio_score =
  0.50 * defensive_quality_score
  0.30 * low_turnover_momentum_score
  0.20 * regime_overlay_score
```

这样做的目的：

- 保留当前主策略已验证的低换手动量优势。
- 用质量和低波降低风格切换风险。
- 让跨市场信号继续做 overlay，而不是主 ranker。

### 5.4 P1：改造质量策略，而不是放弃质量策略

`quality_growth_price_v1` 当前失败，但方向不能放弃。建议改为：

```text
quality_low_turnover_monthly_v1
```

核心变化：

- 月频调仓。
- top_n 扩到 `10 / 20`。
- 取消过强的短线趋势过滤。
- 质量因子先做横截面排名，再叠低波和低换手。
- 对财报数据按公告日和报告期输出 PTI 说明。

### 5.5 P1：建立过拟合诊断作为策略准入门槛

T2.4 的过拟合诊断工具应进入研发流程。建议第一版先不追求复杂统计，只做：

- OOS 衰减
- fold 稳定性
- 参数邻域稳定性
- 成本敏感性
- 收益集中度

并设定硬规则：

- `overfit_risk_level = high / critical` 的策略不能进入 `brief watchlist`。
- OOS 折数不足时，报告必须标注证据不足。
- 参数邻域不稳定时，即使 gate 通过，也只能观察。

### 5.6 P2：SVM / XGBoost 只做二阶段模型

中文文献支持 SVM 多因子选股，但当前项目不应直接上 SVM 做黑盒主策略。建议路径：

1. 先筛出 5-10 个稳定因子。
2. 用月频标签训练上涨概率或相对收益分位。
3. SVM / XGBoost 只做二阶段 rerank。
4. 输出特征重要性、分年度表现和成本后表现。

第一版模型目标不是收益最大化，而是验证：

- 是否改善主策略候选质量
- 是否降低回撤
- 是否降低错误买入
- 是否能在 live profile 成本下保留优势

## 6. 建议任务拆分

### T2.5：因子有效性诊断报告

- 新增因子诊断脚本。
- 输出 IC、ICIR、分组收益、相关矩阵、覆盖率。
- 先不改变策略交易逻辑。

### T2.6：低波低换手质量候选策略

- 新增 `low_vol_low_turnover_quality_v1`。
- 接入 `phase0/strategies/registry.py`。
- 加入 compare，但默认不得替换 selected candidate，直到通过完整 gate。

### T2.7：质量策略低换手改造

- 新增 `quality_low_turnover_monthly_v1`。
- 从 `quality_growth_price_v1` 继承数据字段，但重做调仓节奏和评分方式。

### T2.8：主策略 sleeve 化

- 把 `legacy_momentum_low_turnover_v1` 输出拆成可组合 score。
- 支持与低波、质量、换手因子加权。

### T2.9：SVM / XGBoost 二阶段 rerank

- 只在因子诊断通过后启动。
- 模型输出必须可解释、可复现、可做样本外比较。

| 顺序 | 任务 | 原因 |

| 6 | SVM / XGBoost rerank | 在稳定因子基础上做模型增强 |

## 8. 最终判断

当前主策略 `legacy_momentum_low_turnover_v1` 不是偶然的无效方向，它证明了项目里最重要的工程判断：在 A 股个人量化场景下，交易节奏和成本控制比堆复杂信号更重要。

但它也不是长期终局。它仍然是动量策略，缺少 A 股文献和综合报告中最推荐的低波、低换手和质量因子的完整合成。当前失败候选的共同教训是：复杂过滤和高换手不能替代稳定因子。

下一轮策略研发的主线应从：

```text
动量策略调参
```

切换为：

```text
因子有效性诊断 -> 低波低换手质量组合 -> 低换手动量 sleeve -> 过拟合诊断 gate
```
