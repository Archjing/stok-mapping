# 策略实验解读

在 stok-mapping 项目中，每次策略验证、回测或候选策略对比结束后，使用这个 skill 生成面向个人决策辅助场景的中文解释。

## 输出原则

- 用通俗中文解释，不只复述指标名。
- 明确说明结果是否达到当前阶段目标，但不要把回测包装成未来收益承诺。
- 解释策略“实际怎么交易”，避免只停留在算法描述。
- 必须区分“本次实验结论”和“正式进入下一阶段还需要的验证”。
- 如果策略逻辑或参数刚刚被修改，必须说明修改理由和参考依据，延续项目既有要求。

## 固定解读结构

### 1. 结果意义

逐项解释核心指标：

- `sharpe_mean`：单位风险收益，重点对比阶段门槛。
- `annualized_return_mean`：扣除当前成本后的年化收益水平。
- `max_drawdown_mean`：最大回撤，说明资金曲线压力。
- `win_rate_mean`：胜率，说明它不是唯一判断标准。
- `turnover_annual_mean`：年化换手，重点说明交易成本和可执行性。

最后给出一句阶段判断，例如：

> 这说明该策略已经进入值得重点验证的主策略候选阶段，但还不能仅凭一次结果宣布正式完成 Phase 0。

### 2. 操作方法

用自然语言描述策略如何买、如何持有、如何卖：

- 用什么信号筛股票。
- 大致买多少只。
- 是否分散持仓。
- 调仓频率高低。
- 什么时候继续持有。
- 什么时候卖出或替换。

避免使用过多公式；必要公式只作为补充。

### 3. 个人使用工作流

按实际使用顺序描述：

- 收盘后更新数据。
- 盘前生成报告。
- 查看推荐持仓、买入、卖出、替换清单。
- 人工确认停牌、涨跌停、成交量、公告、异常开盘。
- 记录实际成交，后续用于实盘偏差评估。

### 4. 约束条件

必须说明：

- 依赖数据完整性和时间线正确性。
- 回测不等于真实成交。
- A 股涨跌停、停牌、流动性会影响执行。
- 极端行情和政策冲击可能使历史规律失效。
- 股票池过窄可能被单票主导，过宽可能稀释信号。

### 5. 稳定性判断

从以下角度说明：

- 是否通过阶段门槛。
- 是否降低换手和成本敏感性。
- 是否需要完整候选策略对比。
- 是否需要成本敏感性测试。
- 是否需要分年度、样本外和模拟实盘验证。

## 归档要求

如果用户要求归档，将解读保存到 `logs/` 下，文件名使用：

```text
YYYY-MM-DD-strategy-experiment-interpretation.md
```

归档内容应包含：

- 本次回测关键指标。
- 指标通俗解释。
- 策略操作方法。
- 个人使用工作流。
- 约束条件。
- 稳定性判断。
- 下一步验证要求。
