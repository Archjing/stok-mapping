## 一、材料解读摘要

本项目基于两份核心研究材料构建分析框架：

### 1.1 `us-cn-stock-correlation-mapping` 报告

报告给出了一套精确的量化映射框架，核心理念是**"外部冲击决定开盘，内生逻辑决定收盘"**：

**三层映射关系（按可靠性排序）：**

- **🥇 隔夜情绪传导（最稳定、最快）**：纳指 >2% 波动 → A股次日同向开盘概率 >70%。VIX > 25 → 全球 risk-off → A股承压。时滞：T+0（隔夜）。
- **🥈 资金流向（中等稳定，正在减弱）**：美股波动 → 外资减配/北向资金流出 → A股承压。但 2021 年以来外资影响力持续下降。
- **🥉 产业基本面映射（最持久，板块>大盘）**：英伟达→光模块（强）、费城半导体→A股半导体（强）、苹果→果链（强）、特斯拉→新能源（中）。月线级别纳指与上证几乎零相关。

**7 个关键跟踪指标：** 纳斯达克100、费城半导体(SOX)、标普500、VIX、KWEB（中概互联）、美元指数(DXY)、10Y美债收益率。

**A股独立行情的触发条件（A股何时"不跟"）：** 国内政策驱动 > 估值差异 > 外资退潮 > 宏观政策周期分化。

### 1.2 《GPT时代的量化交易》导读

本书提供了量化交易的五大类策略方法论和工程技术基础：

- **五大类策略体系**：基本面量化（巴菲特式）、资产配置量化（达利欧全天候）、阿尔法量化（西蒙斯因子挖掘）、贝塔量化（克罗趋势追踪）、另类量化（索罗斯事件驱动）
- **KISS 原则**：简单策略优于复杂策略。奥卡姆剃刀——参数越少越好。
- **因子建模**：因子 = 能解释股票收益差异的变量。Fama-French 三因子是基础，模型 = 多因子加权组合。
- **凯利公式仓位管理**：f = (bp - q) / b，实践中使用"半凯利"（f/2）降低波动。
- **策略有效性评估**：年化收益率、夏普比率、最大回撤、胜率、盈亏比、Calmar比率。
- **GPT 应用方向**：代码生成、自然语言数据查询、研究报告自动生成、非结构化数据→结构化转换、因子构思辅助。
- **核心哲学**：底层逻辑 > 编程工具。GPT 降低代码门槛，理解策略逻辑才是关键。

### 1.3 两份材料的交叉印证

| 量化理念 | 报告支撑 | 本书支撑 |
|---------|---------|---------|
| 因子思维 | 纳指涨跌幅→A股次日开盘方向（单因子规则） | Fama-French 多因子模型 |
| 概率思维 | "纳指跌>2% → A股低开概率>70%" | 上帝视角假设，没有必然只有大概率 |
| 简单规则 | 隔夜法则只需看纳指/VXV/KWEB 三个数 | KISS 原则，奥卡姆剃刀 |
| 板块思维 | 板块映射远强于大盘映射 | "所有的阿尔法都是贝塔" |
| 信号验证 | 盘中验证隔夜映射是否兑现 + 独立行情检测 | 回测验证，策略有效性评估 |

## 二、系统定位

**每日跨市场量化研判与选股系统**——利用美股→A股、港股→A股的事实传导映射关系，综合技术面、资金面、基本面因子，自动生成**每日盘前简报、映射选股池、买卖点信号建议**，通过邮件投递。

核心差异：不是通用量化平台，而是**专门利用跨市场关联规律**的研判工具。输入三市场动态数据，输出 A 股可操作建议。

### 输入/输出全景

```
输入层                      分析引擎层                    输出层
────────────────────────────────────────────────────────────────
美股收盘 → 隔夜映射引擎 → A股开盘方向预判 ─┐
港股走势 → 港股领先指标 → A股情绪验证      ├→ 综合评分 → 选股池 → 买卖点建议
A股数据 → 内生逻辑引擎 → 板块/个股筛选    ─┘
港股实时 → 外资情绪代理 → 方向确认
政策新闻 → NLP 情绪解析 → 权重调整
```

## 三、三大传导路径的量化落地

### 引擎 #1：隔夜情绪传导（最稳定）

```
输入: 纳指涨跌幅 / SOX涨跌幅 / VIX / KWEB / A50期货
规则:
  if 纳指 > +2%:    A股科技次日高开概率 >65% → 生成"偏多"信号
  if 纳指 < -2%:    A股科技次日低开概率 >70% → 生成"偏空"信号
  if VIX > 25:      全球risk-off → A股承压 → 减仓信号
  if VIX < 15:      风险偏好正常 → 正常仓位
  if KWEB 涨/跌 >2%: 中概情绪传导 → A股情绪同向
输出: 次日开盘方向 + 置信度 + 风险等级（绿/黄/橙/红）
```

### 引擎 #2：板块映射引擎（选股核心）

| 美股触发事件 | A股映射标的 | 映射强度 | 触发阈值 |
|-------------|-----------|---------|---------|
| 英伟达(NVDA)涨跌 | 中际旭创/新易盛/天孚通信/中科曙光 | **强** | >3% |
| 费城半导体(SOX)涨跌 | 中芯国际/北方华创/韦尔股份/澜起科技 | **强** | >2% |
| 苹果(AAPL)涨跌/指引 | 立讯精密/歌尔股份/蓝思科技/鹏鼎控股 | **强** | >3% |
| 特斯拉(TSLA)涨跌 | 宁德时代/比亚迪/赣锋锂业/天齐锂业 | **中** | >3% |
| Meta资本开支变化 | 光模块/算力租赁标的 | **中高** | 财报事件 |
| 微软/谷歌涨跌 | 云计算/SaaS/AI应用标的 | **中** | >2% |

### 引擎 #3：港股→A股领先指标

> ⚠️ 关键补充：由于港交所 2024 年 4 月公告调整后，北向实时买入/卖出/总成交额不再提供、持股查询改为季度披露（[HKEX 2024-04-12](https://www.hkex.com.hk/News/Market-Communications/2024/2404122news?sc_lang=en)），港股实时走势成为了解外资对 A 股情绪的最重要**盘中代理指标**。

```
恒生科技指数实时走势 → A股科技板块盘中方向（外资情绪的即时代理）
恒生指数实时走势     → A股大盘盘中情绪
AH溢价指数           → 同一公司A/H股价差 → 估值信号
港股通资金流向(南向) → 内地资金对港股的态度 → 间接反映市场风险偏好
离岸人民币(CNH)实时   → 外资对中国资产的即时定价
```

## 四、多因子选股与买卖点框架

### 4.1 多因子打分模型

```
单只个股总分 = Σ(因子得分 × 权重)

因子池:
├─ 映射信号因子 (40%): 隔夜映射方向 × 板块映射强度 × 历史准确率
├─ 技术面因子 (25%):   均线排列 / RSI位置 / 量价关系 / MACD
├─ 资金面因子 (20%):   北向持股变化 / 主力资金流向 / 成交量异常
├─ 基本面因子 (10%):   PE分位 / ROE / 营收增速
└─ 情绪面因子 (5%):    新闻情绪打分 / 研报评级变化
```

### 4.2 五级买卖点信号

| 信号 | 触发条件 | 操作建议 | 仓位 |
|------|---------|---------|------|
| 🟢 强买入 | 映射正向 + 技术低位 + 资金流入 + Score>80 | 开仓/加仓 | 凯利满仓 |
| 🟡 轻仓试探 | 映射正向但技术偏高 + Score 60-80 | 小仓位试探 | 半凯利 |
| ⚪ 观望 | 映射方向不明 + Score 40-60 | 持仓不动 | 维持现有 |
| 🟠 减仓 | 映射负向 + VIX走高 + Score 20-40 | 减半仓 | 减至半凯利 |
| 🔴 清仓 | 映射负向 + 隔夜>3%暴跌 + VIX>30 | 清仓避险 | 清仓 |

### 4.3 凯利公式辅助仓位管理

```
f = (bp - q) / b
b = 预期盈亏比（从历史映射胜率估算）
p = 信号历史胜率
f = 建议仓位比例

实践：使用"半凯利"(f/2)，控制单只<10%、单板块<30%
```

## 九、回测精度与 Qlib 使用策略

### 9.1 回测精度选择

**建议：日线为主，Phase 2 补充 60 分钟线。**

| 精度 | 用途 | 阶段 |
|------|------|------|
| 日线 | 映射信号验证、策略回测、报告生成 | Phase 1 起 |
| 60分钟线 | 盘中买点精调、日内映射验证 | Phase 2 可选 |
| 分钟级 | 暂不采用 | — |

理由：
- 报告中所有映射规律都是日级别（隔夜传导、次日开盘），分钟级数据对核心决策没有增益
- yfinance/akshare 的分钟级数据质量和覆盖度不如日线
- 60 分钟线仅用于优化买入时机（例如低开后的最佳入场时间窗口）

### 9.2 Qlib 引入策略

| Qlib 能力 | 匹配度 | 引入阶段 | 用途 |
|-----------|--------|---------|------|
| Alpha158 因子 | 中 | Phase 3 | 增强 scoring_model 的因子库 |
| GBDT/LightGBM 预测 | 高 | Phase 3 | 训练"映射信号→涨跌"分类器 |
| 自动化因子挖掘 | 低 | — | 暂不采用 |
| 回测框架 | 低 | — | 已被 stok-quant 覆盖 |

**结论：Phase 3 引入 Qlib 的模型层**，用历史映射数据训练分类器，验证手动规则（>2%阈值等）的科学性。**Phase 1-2 完全不需要**。

## 十、期货数据在研判中的角色

**不用于直接交易对冲，而是作为领先情绪指标纳入引擎 #1：**

| 期货指标 | 信号含义 | 数据源 |
|---------|---------|--------|
| 新加坡A50期货（盘前） | 外资对次日A股的方向押注 | yfinance |
| 沪深300期货升贴水 | 聪明钱的多空倾向 | akshare |
| 中证500/1000期货基差 | 中小盘风险偏好 | akshare |
| 恒生指数期货（盘前） | 港股开盘方向先行指标 | yfinance |

这些数据 yfinance + akshare 都能获取，作为引擎 #1 的增强输入，无需独立模块。

## 十三、关键决策记录

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 选股范围 | 映射板块标的池（~50 只） | 板块映射远强于大盘映射，聚焦才有精度 |
| 推送渠道 | 邮件（SMTP） | 成本低、可归档、支持富文本 |
| 港股用途 | 仅作为 A 股领先指标 | 不独立分析港股选股 |
| 回测精度 | 日线为主 | 映射规律是日级别，分钟级无增益 |
| Qlib 引入 | Phase 3，仅模型层 | Phase 1-2 手动规则更可控 |
| 期货数据 | 作为情绪指标，不做交易 | A50/基差提供盘前方向信号 |
| 部署方式 | Docker Compose | WSL + ECS 完全统一 |
| 数据存储 | SQLite→PostgreSQL | 开发用 SQLite，生产可切换 |
