# 因子有效性诊断报告

## 运行口径

- 价格口径：`qfq_asof`，即按每个历史 as-of date 重新计算“当时可见的前复权”价格特征。
- 股票池口径：point-in-time 股票池，使用每个验证折训练期结束时可见的股票池。
- 标签口径：同一股票未来 20 个交易日收益，计算为 `close.shift(-20) / close - 1`。
- 验证样本：4 个有效 PIT / `qfq_asof` 验证折。
- 重要限制：本报告只证明“因子层面有无统计证据”，不等于策略已经可以进入实盘模拟。策略还需要组合构造、换手控制、成本后回测、过拟合诊断和准入报告。

## 总结论

本次共诊断 15 个因子：

- 可进入策略组合观察：6 个，分别是 `low_pb`、`low_vol60`、`low_turnover_rate`、`low_vol20`、`ep`、`cash_flow_quality`
- 仅观察：1 个，`reversal_mom3`
- 淘汰：8 个，分别是 `reversal_mom5`、`low_amount_ratio20`、`profit_growth`、`roe`、`mom20`、`revenue_growth`、`mom60`、`low_debt_to_asset`
- 数据缺失：0 个

直接结论是：当前 A 股 PIT / `qfq_asof` 口径下，低估值、低波动、低换手和现金流质量有正向因子证据；传统中短期动量、收入/利润增长、ROE、低负债率在当前验证口径下没有通过。

## 被测因子含义

本报告中的因子方向已经统一为“数值越高越好”。带有 `low_` 前缀的因子通常是把原始指标取负数后得到，例如 `low_pb = -pb`，表示 PB 越低，因子得分越高。

| 因子 | 含义 |
| --- | --- |
| `low_pb` | 低市净率因子，原始 PB 越低，因子值越高，代表低估值暴露。 |
| `low_vol60` | 低 60 日波动率因子，过去 60 个交易日收益波动越低，因子值越高。 |
| `low_turnover_rate` | 低换手率因子，日换手率越低，因子值越高，代表交易活跃度较低。 |
| `low_vol20` | 低 20 日波动率因子，过去 20 个交易日收益波动越低，因子值越高。 |
| `ep` | 盈利收益率因子，计算为 `1 / pe_ttm`，市盈率越低且盈利为正时通常因子值越高。 |
| `cash_flow_quality` | 现金流质量因子，来自公告日 point-in-time 财务数据，衡量经营现金流相对利润的质量。 |
| `reversal_mom3` | 3 日反转因子，计算为 `-mom3`，过去 3 日跌得越多，因子值越高。 |
| `reversal_mom5` | 5 日反转因子，计算为 `-mom5`，过去 5 日跌得越多，因子值越高。 |
| `low_amount_ratio20` | 低成交额放大比例因子，计算为 `-amount_ratio20`，当日成交额相对 20 日均值越低，因子值越高。 |
| `profit_growth` | 利润增长因子，来自公告日 point-in-time 财务数据，衡量利润同比/环比增长表现。 |
| `roe` | 净资产收益率因子，来自公告日 point-in-time 财务数据，衡量股东权益盈利能力。 |
| `mom20` | 20 日动量因子，过去 20 个交易日涨幅越高，因子值越高。 |
| `revenue_growth` | 收入增长因子，来自公告日 point-in-time 财务数据，衡量营业收入增长表现。 |
| `mom60` | 60 日动量因子，过去 60 个交易日涨幅越高，因子值越高。 |
| `low_debt_to_asset` | 低资产负债率因子，计算为 `-debt_to_asset`，资产负债率越低，因子值越高。 |

## 分组收益解读

分组规则：每天把因子按从低到高排序后分为 5 组。由于本报告中的因子方向已经统一为“数值越高越好”，第 5 组是 Top 组，第 1 组是 Bottom 组。

有效因子的典型表现：

- `low_pb`：Bottom 组未来 20 日平均收益 -0.0107，Top 组 0.0060，Top-Bottom 为 0.0166，分组收益最清晰。
- `low_vol60`：Bottom 组 -0.0095，Top 组 0.0026，Top-Bottom 为 0.0121，低波动有效。
- `ep`：Bottom 组 -0.0052，Top 组 0.0031，Top-Bottom 为 0.0083，估值收益率有效。
- `cash_flow_quality`：Bottom 组 -0.0046，Top 组 0.0035，Top-Bottom 为 0.0081，现金流质量有效。
- `low_turnover_rate`：Bottom 组 -0.0038，Top 组 0.0010，Top-Bottom 为 0.0048，有效但收益差距较小。
- `low_vol20`：Bottom 组 -0.0040，Top 组 0.0025，Top-Bottom 为 0.0065，有效但换手压力高于 60 日低波。

被淘汰因子的典型表现：

- `mom20`：Top 组 -0.0090，Bottom 组 -0.0009，Top-Bottom 为 -0.0081，说明 20 日动量方向反了。
- `mom60`：Top 组 -0.0102，Bottom 组 0.0014，Top-Bottom 为 -0.0116，中期动量失败更明显。

## 相关性观察

- `low_vol20` 与 `low_vol60` 相关性约 0.8446，二者高度重叠。策略中不宜简单等权叠加，应优先用 `low_vol60` 做稳定低波，或降低 `low_vol20` 权重。
- `ep` 与 `low_pb` 相关性约 0.7552，二者都属于低估值暴露。可以组合使用，但需要防止估值因子过度集中。
- `low_turnover_rate` 与低波因子有中等相关性，和 `low_vol20` 约 0.6244，和 `low_vol60` 约 0.6451，说明低换手与低波存在共同防御属性。
- `profit_growth` 与 `revenue_growth` 相关性约 0.6122，但两者本次都被淘汰，不能因为相关性高而作为质量因子保留。
- `reversal_mom3` 与 `reversal_mom5` 相关性约 0.7231，但二者证据都弱，不应作为主线。

## 对下一步策略研发的建议

首版 `low_vol_low_turnover_quality_v1` 不应沿用旧的动量主线。建议从以下因子构造：

- 核心防御：`low_vol60`
- 估值：`low_pb`、`ep`
- 低交易活跃度：`low_turnover_rate`
- 质量：`cash_flow_quality`

需要谨慎处理：

- `low_turnover_rate` 和 `low_vol20` 的逐日换手代理很高，策略必须采用低频调仓，例如月频或至少 20 日调仓，并加入持仓继承/换手惩罚。
- `low_pb` 与 `ep` 高相关，权重不能简单双倍放大估值暴露。
- `mom20`、`mom60` 不应作为当前主 ranker；如果保留，只能作为很弱的辅助 sleeve 或完全排除。
- `roe`、`profit_growth`、`revenue_growth`、`low_debt_to_asset` 暂不进入首版质量组合，避免把负向证据硬塞进策略。

建议首版候选权重方向：

```text
defensive_quality_score =
  0.30 * low_vol60_rank
+ 0.25 * low_pb_rank
+ 0.20 * ep_rank
+ 0.15 * low_turnover_rate_rank
+ 0.10 * cash_flow_quality_rank
```

这只是研发起点，不是最终策略参数。下一步必须通过成本后 walk-forward、换手约束、行业约束和 strategy-admission 报告验证。
