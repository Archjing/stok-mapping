**能做有效的中低频量化策略；不适合幻想成只靠开收盘盯价就稳定日内套利。**

我按量化研究口径判断：

**核心结论**
只用日线数据，加上开盘/收盘附近实时价格监看，可以实施有价值策略，前提是：

- 持仓周期以 `数日到数周` 为主，而不是日内高频。
- 策略目标是组合层面的长期超额收益和回撤控制。
- 交易动作集中在 `盘前计划、开盘确认、收盘复核、次日执行`。
- 必须严格处理成本、滑点、涨跌停、停牌、T+1、成交失败。

A 股主板有涨跌幅限制，普通股票通常 `10%`，风险警示股票 `5%`；上交所也说明股票撮合按价格优先、时间优先，集合竞价和连续竞价机制不同。开收盘本身不是普通连续交易环境。来源：上交所交易机制说明、深交所交易规则。([english.sse.com.cn](https://english.sse.com.cn/start/trading/mechanism/)) ([amac.org.cn](https://www.amac.org.cn/governmentrules/zcgz_zlgz/zlgz_gmjj_jysgz/201912/t20191222_2864.html))

**为什么可行**
日线策略的优势是噪声更少、实现成本低、对基础设施要求低，适合做：

- 行业/板块轮动
- 低换手动量
- 趋势跟随
- 低波动/质量/估值叠加
- 市场宽度和风险状态过滤
- 隔夜外盘、港股、宏观信号 overlay

开盘附近实时价格的价值不是“抢交易”，而是做执行过滤：

- 高开过多，避免追价。
- 跌停/涨停附近，标记无法成交。
- 开盘流动性异常，推迟或取消。
- 个股跳空破坏信号，降权。

收盘附近实时价格的价值是确认日线信号：

- 收盘是否仍在趋势/动量条件内。
- 是否进入涨跌停或流动性风险。
- 是否需要生成次日调仓建议。

上交所投教资料明确，A 股有开盘集合竞价、连续竞价和 `14:57-15:00` 收盘集合竞价，收盘集合竞价期间只接受申报、不接受撤销申报。([edu.sse.com.cn](https://edu.sse.com.cn/best/audio/tjxwc/c/5331843.shtml)) 所以“开收盘监看”要当成执行风控点，而不是高频 alpha 来源。

**为什么有限**
只用日线和开收盘价格，做不了这些事：

- 盘口微结构套利
- 高频做市
- 秒级/分钟级反转
- 纯消息抢跑
- 可靠日内 T+0 股票交易

A 股股票还有 T+1 约束，今天新买的股票不能当天卖出。这会削弱很多日内策略的可执行性。再加上印花税、佣金、滑点和冲击成本，短周期高换手很容易把纸面收益吃掉。证券交易印花税自 2023 年 8 月 28 日起减半征收，但它仍然是卖出端成本的一部分。([shanghai.chinatax.gov.cn](https://shanghai.chinatax.gov.cn/tax/zcfw/zcfgk/yhs/202308/t468451.html))

**适合的盈利目标**
比较现实的目标不是“每天赚钱”，而是：

- 长期跑赢基准，比如沪深300、中证500、中证1000或行业指数。
- 控制最大回撤。
- 降低换手。
- 在 OOS / walk-forward 中保持正收益和可解释性。
- 实盘模拟中能成交，不靠理想价格。

对个人量化研究来说，比较合理的“有价值盈利”是：  
**在可承受回撤下，获得稳定的风险调整后收益和相对基准超额收益。**  
如果目标是“低风险、每天有收益、年化很高”，那不现实。

**对本项目的建议**
你现在的方向是对的：继续做 `daily-brief + 连续模拟仓位 + 调仓建议`。

建议策略形态是：

```text
日线信号生成
-> 盘前观察池
-> 开盘价格/涨跌停/流动性检查
-> 生成可执行调仓建议
-> 用户确认或程序模拟成交
-> 收盘复核
-> 更新连续持仓 ledger
```

核心不要追求“开盘买、收盘卖”的日内赚钱，而是做：

- 低换手组合
- 多标的分散
- 开收盘执行风控
- 连续模拟账户
- 成本后回测
- 每日可复盘报告

一句话判断：  
**能做，而且值得做；但它应该是中低频量化投资系统，不是日内短炒系统。**

## Assistant / 助手 - 2026-06-02 11:12:46 +0800

简洁判断：

| 方法 | 是什么 | 50w 以下个人是否适合 |
| --- | --- | --- |
| 文本情绪过滤 | 用新闻、公告、研报标题、社媒、财报文本等判断市场情绪，只作为选股/风控过滤器 | **可以作为辅助，不适合作主策略** |
| 融资融券/LSTM 双边策略 | 用 LSTM 预测价格/收益，再结合融资做多、融券做空或多空组合交易 | **不适合** |

**文本情绪过滤方法**

它不是直接“看新闻买股票”，而是把文本转成信号：

```text
新闻/公告/研报标题
-> 情绪分数：正面/负面/中性
-> 事件标签：业绩、监管、并购、减持、行业政策
-> 过滤股票池或降低风险暴露
```

适合个人投资者的用法：

- 剔除重大负面新闻股票。
- 给已有日线策略加解释标签。
- 在日报里提示“为什么不追买 / 为什么减仓观察”。
- 做候选池过滤，而不是单独下单。

不适合做主策略，因为文本源质量、延迟、噪声、误判都很高。个人资金 50w 以下，最好把它当作“风控和解释层”。

**融资融券/LSTM 双边策略**

这个方向复杂得多：

```text
日线/分钟线/因子
-> LSTM 预测未来收益
-> 融资买入看多标的
-> 融券卖出看空标的
-> 多空组合 / 杠杆组合
```

不适合 50w 以下个人，原因很直接：

- 融资融券开户通常要求最近 20 个交易日日均证券类资产不低于 50 万，且交易经验满半年。证监会和上交所规则都有这个门槛。([csrc.gov.cn](https://www.csrc.gov.cn/csrc/c106256/c1654005/content.shtml)) ([sse.com.cn](https://www.sse.com.cn/lawandrules/sselawsrules2025/trade/specific/margin/c/c_20250616_10782015.shtml))
- 融券标的不稳定，普通个人很难稳定借到券。
- LSTM 容易过拟合，对小资金没有天然优势。
- 杠杆会放大回撤，策略错一次可能损失很重。
- 多空交易还要处理利息、保证金、强平、展期、融券成本。

**结论**

对你当前项目：

- `文本情绪过滤`：可以做，定位为 **日报解释层 / 风险过滤器 / 候选池标签**。
- `融资融券/LSTM 双边策略`：当前不做，尤其不适合 50w 以下个人投资者。

更适合你的路线是：

```text
日线主策略
+ 开盘/收盘执行检查
+ 文本情绪风险标签
+ 连续模拟仓位
+ 调仓建议
```

不要把融资融券/LSTM 双边策略放进当前主线。

## Assistant / 助手 - 2026-06-02 11:18:30 +0800

`0.05` 指的是 **证券交易印花税税率 0.05%**，也就是通常说的 **千分之 0.5 / 0.5‰**。

A 股股票交易印花税原来常见口径是卖出端 `0.1%`，2023 年 8 月 28 日起“减半征收”，所以变成：

```text
0.1% / 2 = 0.05%
```

也就是：

```text
卖出 100,000 元股票，印花税约 50 元
```

我用 `2023` 做关键词，是因为这项政策的**发布和生效时间**就是 2023 年。官方公告标题和文号也是：

```text
财政部 税务总局公告 2023 年第 39 号
自 2023 年 8 月 28 日起，证券交易印花税实施减半征收
```

所以搜索时加 `2023` 是为了精准找到原始政策文件，而不是表示这个政策只适用于 2023 年。

你指出“现在是 2026 年”是对的。严谨说法应该是：

- `2023`：政策出台年份
- `0.05%`：减半后的税率口径
- `2026`：当前使用时要确认是否仍未被新政策替代
