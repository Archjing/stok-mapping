# Harness Iteration Brief - 2026-06-25 - I50 Strong Market Benchmark-Aware Core Design

> 这份简报是预注册设计，不是回测结果，不生成交易信号。

## 一句话结论

下一条强沪深300候选策略应从“强市场里主动选股”改成“强市场里先贴住沪深300核心权重，再保留有限主动增强”。候选暂定名：

```text
strong_market_benchmark_aware_core_v1
```

它不是复制沪深300，也不是固定买前20只；它的目标是补齐策略池里“强沪深300行情参与型”这一角色。

## 为什么要新设计

I49 说明 `strong_market_stable_core_base_v1` 的问题已经不是单纯换手过高：

| I49 证据 | 含义 |
| ---- | ---- |
| 强基准阶段平均实盘仓位 `39.18%` | 仓位仍偏低 |
| 平均持有沪深300权重 `22.33%` | 持到的基准核心权重不足 |
| Top20 覆盖率 `59.14%` | 核心权重股仍有明显漏配 |
| 行业 L1 偏离 `1.1456` | 行业结构相对沪深300偏离较大 |
| 强基准阶段超额总收益 `-4.27%` | 没有形成强市场相对优势 |

所以继续调卫星仓参数意义不大。下一轮应重写候选池和权重构造，让“基准核心权重贴近度”成为策略设计的一等约束。

## 策略角色

| 项目 | 设计 |
| ---- | ---- |
| 策略池角色 | 强沪深300 / 强市场参与型候选 |
| 适用市场 | 沪深300强趋势、风险偏好较高、核心权重股主导上涨 |
| 不适用市场 | 弱基准、风险压力、强主题但非沪深300核心驱动 |
| 当前身份 | research-only 预注册候选 |
| 禁止用途 | 不进入 paper review、模拟账户、日报、watchlist 或实盘辅助，直到通过 admission |

## 设计边界

做：

- 使用 T-1 可见的 `cn_index_weights_asof`。
- 使用 PIT universe 与 `qfq_asof` 价格。
- 显式保留沪深300核心权重候选。
- 把趋势、流动性、风险、行业相对强弱用于排序和降权，不再作为核心股硬过滤器。
- 使用持仓级 CSI300 attribution 验证真实参与度。

不做：

- 不复制沪深300。
- 不固定买沪深300前20只。
- 不使用未来指数权重。
- 不降低 admission gate。
- 不用单折强表现替代多折稳定性。

## 初版组合结构

| 层 | 作用 | 预算 |
| ---- | ---- | ---: |
| `benchmark_aware_core_sleeve` | 贴近沪深300核心权重和行业结构 | `75%` - `90%` |
| `alpha_adjustment_sleeve` | 保留少量主动增强空间 | `10%` - `25%` |

核心层先从沪深300 as-of 权重出发，不从纯 alpha 排名出发。主动因子只负责在可见核心权重里做轻量排序和风险降权。

## 市场状态与目标仓位

| 市场状态 | 目标仓位 | 说明 |
| ---- | ---: | ---- |
| risk pressure | `0%` - `20%` | 避免在弱基准里硬贴指数 |
| mixed / neutral | `35%` - `45%` | 保留低频核心观察仓，防止弱转强时完全错过 |
| strong CSI300 | `65%` - `75%` | 强市场主参与状态 |

强市场识别只使用 T-1 可见指数数据。相比 I18，不应再用过窄的波动过滤把强基准阶段大量排除。

## 候选池生成

1. 从 T-1 CSI300 权重表取核心候选：
   - `core_seed_top_n = 80`
   - 或累计权重达到 `70%`
2. 合并 PIT panel：
   - 若核心股在常规 panel 外，但有 as-of 权重和本地价格数据，应进入 research-only core seed panel。
3. 基础硬过滤只剔除：
   - 缺价格 / 缺收益；
   - 不可交易；
   - 明显停牌或涨跌停无法执行；
   - 数据时间线不可信。
4. 不再因短期趋势、低流动性排名、行业弱势直接剔除沪深300核心股。

## 排序与权重

核心层建议使用“基准权重锚 + 主动评分”的混合权重：

```text
core_score =
  0.55 * benchmark_weight_rank
  + 0.15 * mom60_rank
  + 0.10 * mom20_rank
  + 0.10 * liquidity_rank
  + 0.05 * low_vol_rank
  + 0.05 * industry_relative_rank
```

权重构造建议：

- 初始权重以 CSI300 权重为锚。
- 使用主动评分做温和倾斜，不允许完全覆盖基准权重锚。
- 单票上限保持审计，初步建议 `6%` - `8%`。
- 如果主动卫星仓导致 Top20 覆盖或行业贴近度下降，应自动缩小卫星预算。

## 预注册验收指标

这些指标不是 admission 替代品，而是防止策略再次“名字叫强市场、实际没参与”。

| 验收项 | 最低要求 |
| ---- | ---: |
| 强基准阶段平均 live exposure | `>= 60%` |
| 强基准阶段持有沪深300权重 | `>= 35%` |
| 强基准阶段 Top20 覆盖率 | `>= 70%` |
| 强基准阶段 Top20 漏配权重 | `<= 8%` |
| 强基准阶段行业 L1 偏离 | `<= 0.90` |
| 年化换手均值 | `<= 3.0` |
| 年化换手最大值 | `<= 5.0` |
| 正超额折比例 | `>= 60%`，并继续观察是否能提高到 `75%` |
| admission | 不降低现有 gate |

## 停止条件

如果出现以下情况，应停止，不继续小参数调优：

- 强基准阶段持有沪深300权重仍低于 `30%`。
- Top20 覆盖率仍低于 `60%`。
- 行业 L1 偏离仍高于 `1.10`。
- 年化换手最大值超过 `5.0`。
- 收益只来自单一折、单一行业或少数高权重个股。
- 相对沪深300仍长期负超额。

## 关键风险

| 风险 | 控制方式 |
| ---- | ---- |
| 变成指数复制 | 保留 alpha tilt，但必须先满足权重覆盖和行业贴近 |
| 事后调参 | 先固定验收指标，再实现 |
| 高权重股过度集中 | 单票上限 + 行业主动偏离审计 |
| 未来函数 | 只用 T-1 可见指数权重和 PIT 数据 |
| 强市场策略在弱市场拖累 | 使用 risk pressure 降仓规则 |
