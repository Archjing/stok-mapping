# I39 Strong Market Candidate Generation Redesign Spec

生成时间：2026-06-25 11:27 CST

## 背景

I35、I37 和 I38 的共同结论是：当前强市场参与型候选没有真正参与沪深300主升段。

已验证证据：

- I15/I18/I20 三条强市场候选均为 `reject`，主要失败模式是低参与度和低沪深300权重覆盖。
- I37 `strong_market_effective_participation_v1` 修正单股上限后仍为 `reject`。
- I37 第 5 折强相关窗口平均实盘暴露只有 `10.29%`，持有沪深300权重只有 `2.13%`，前20权重股覆盖只有 `2.79%`。
- I38 第 5 折强市场日平均可买候选只覆盖沪深300约 `9.05%` 权重，当前 panel 可见权重前20股票只覆盖约 `3.93%`。

因此，下一轮不应继续微调组合权重器，而应重构候选生成层。

## 设计目标

强市场参与型策略的目标不是“在强市场里找少数主动 alpha 股票”，而是：

1. 先保证能够参与沪深300核心权重。
2. 再在可参与的核心权重范围内做风险过滤和轻量 alpha 排序。
3. 如果核心权重不可达，策略应明确降级为“暂无合格强市场参与候选”，而不是用低权重尾部股票凑仓位。

## 角色边界

| 角色 | 做什么 | 不做什么 |
| ---- | ------ | -------- |
| 指数参与层 | 保证 CSI300 核心权重可达性，检查 as-of 权重、流动性、停牌和基础可交易性 | 不用过窄动量 / 残差 / 行业相对强弱过滤先砍掉核心权重股 |
| 风险过滤层 | 排除明显不可交易、极端弱势、流动性异常或数据缺失标的 | 不把普通短期回撤直接等同于不可买 |
| alpha 排序层 | 在可参与候选中做轻量排序和权重微调 | 不改变指数参与层的核心权重覆盖目标 |
| 组合约束层 | 控制单股、行业、换手和成本 | 不为了填满仓位突破单股上限 |

## I40 候选方向

候选名暂定：`strong_market_core_reachability_v1`

首版只验证候选生成，不急于作为正式策略候选。

### 候选生成草案

1. 使用 T-1 可见 `cn_index_weights_asof` 取沪深300成分和权重。
2. 先取权重排名前 `N` 或累计权重前 `X%` 的核心成分，例如：
   - Top 60，或
   - 累计权重前 60%。
3. 仅做最基础可交易过滤：
   - PIT 数据存在；
   - qfq_asof 价格可用；
   - 非停牌 / 非缺失成交；
   - 成交额或换手不低于最低可执行阈值；
   - 行业字段可用。
4. 输出每日可达性：
   - 核心成分可达数量；
   - 可达权重；
   - 完整基准 Top20 可达权重；
   - 被过滤核心成分及原因。
5. 只有当可达权重大于最低阈值，才进入组合构造研究。

### 首版不做

- 不直接新增 paper-trade 策略。
- 不引入分钟级盘中信号。
- 不使用未来可见的当日收盘权重。
- 不把 top weight miss 列表解释为买入建议。
- 不绕过行业审计和单股权重上限。

## I40 最小验收

进入策略实现前，先跑只读诊断：

| 验收项 | 最低要求 |
| ------ | -------: |
| 强市场日可达沪深300权重 | >= 50% |
| 强市场日完整基准 Top20 可达权重 | >= 35% |
| 权重 as-of 覆盖率 | 100% |
| 数据缺失解释 | 每日有缺失原因归因 |
| 未来函数风险 | 使用 T-1 或更早可见权重 |

如果这个只读诊断达不到，说明本地数据和候选生成无法支撑强市场指数参与型策略，应停止写策略实现。

## 推荐下一步

I40 应新增一个只读命令或扩展现有 `strategy-filter-diagnostic`：

```text
strategy-core-reachability-diagnostic
```

它不依赖某个策略的 hard filters，而是从沪深300核心权重出发，逐层解释：

```text
T-1 CSI300 core weights
-> PIT price availability
-> tradability / liquidity
-> industry availability
-> risk filter
-> reachable core weight
```

只有该诊断证明核心权重可达，才考虑实现 `strong_market_core_reachability_v1`。
