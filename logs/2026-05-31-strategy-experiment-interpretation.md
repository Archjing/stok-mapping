# 2026-05-31 策略实验解读归档

## 本次回测结果的通俗解释

这组结果的核心意义是：这次“低换手策略”已经明显越过之前设定的 Phase 0 目标线。

`sharpe_mean = 1.0886` 表示单位风险带来的收益比较好。之前的目标是 Sharpe 高于 `0.5`，这次达到 `1.09`，说明策略不是单纯靠冒很大风险换收益。

`annualized_return_mean = 0.1440` 表示年化收益约 `14.4%`。这个水平在扣除当前设定交易成本后仍然成立，说明策略有一定实际意义。

`max_drawdown_mean = -0.1012` 表示平均最大回撤约 `-10.1%`。之前希望最大回撤优于 `-25%`，这次明显达标，说明资金曲线的下跌压力比之前策略小很多。

`win_rate_mean = 0.5129` 表示胜率约 `51.3%`。这不是特别高，但量化策略不一定靠高胜率赚钱，更重要的是盈亏比、回撤和稳定性。这里胜率略高于 50%，配合 Sharpe 和回撤看，是可接受的。

`turnover_annual_mean = 1.50` 表示一年大约换手 `1.5` 次组合。这个很关键，说明策略已经从高频折腾变成了低频持有，交易成本压力会小很多，也更接近“个人决策辅助工具”的目标。

结论：这次结果说明“低换手、宽持有区间、低频调仓、成本惩罚”的方向是有效的，至少已经解决了之前 Sharpe 不够、成本敏感的问题。但它还不能直接宣布 Phase 0 完成，需要再跑一次完整 Phase 0，对比所有候选策略，并确认成本敏感性和样本外结果没有异常。

## 策略操作方法的通俗解释

这条策略通俗说就是：不每天追涨杀跌，只在一批股票里找近期走势较强、风险不过高的票，买入后给它更宽的容忍区间，除非明显掉队，否则继续持有。

它大致按下面逻辑运行：

1. 看股票最近一段时间的动量，比如近 `20` 个交易日表现。
2. 只考虑排名靠前、动量超过一定门槛的股票。
3. 买入时不是只买 1 只，而是买入约 `5-10` 只，分散单票风险。
4. 买入后不是一跌就卖，而是设置一个更宽的“持有区间”。
5. 如果股票只是短期回调，但仍在可接受排名范围内，就继续持有。
6. 如果股票跌出持有区间、动量明显变弱，或者到了调仓日发现更好的标的，才考虑换仓。
7. 调仓频率偏低，目前回测里更有效的参数接近 `20` 个交易日一轮，也就是大约一个月调一次。

简单讲，它不是“今天强就买、明天弱就卖”，而是：强势入选，弱化但未明显掉队就继续拿，明显失效才换。

个人实际交易时，工作流应该是：

1. 每天收盘后更新 A 股数据。
2. 次日早上生成策略报告。
3. 查看当前推荐股票池、建议持仓、需要卖出的股票、需要买入或替换的股票。
4. 只在策略触发调仓日，或持仓明显跌出规则时操作。
5. 下单前人工确认：是否停牌、是否涨跌停、成交量是否足够、是否有重大公告、是否已经出现异常高开低开。
6. 按组合权重分散买入，不要把资金集中到单只票。
7. 记录实际成交价，因为回测价格和真实成交会有差异。

这个策略更适合做成盘前决策辅助，而不是完全自动交易。它给出候选和权重，人再做最后交易可行性检查。

主要约束有这些：

1. 它依赖收盘后的历史数据，不是盘中实时追涨策略。
2. 信号应在数据完整后生成，原则上用于下一个交易日，而不是回头解释当天。
3. 如果数据源延迟、缺失、覆盖率不足，信号可靠性会下降。
4. 如果遇到极端行情，比如全面暴跌、政策冲击、流动性踩踏，历史动量规律可能失效。
5. A 股有涨跌停、停牌、成交量限制，回测不一定完全模拟真实成交困难。
6. 股票池如果过窄，结果容易被少数股票主导；股票池过宽但质量差，也会稀释信号。
7. 当前结果来自 Phase 0 回测，不等于未来收益承诺。

这次结果的稳定性比之前好，关键原因是它降低了换手率。`turnover_annual_mean = 1.50` 表示一年大约只换手 1.5 次组合，交易成本压力小很多，不容易被手续费、滑点吃掉收益。

`sharpe_mean = 1.0886` 和 `max_drawdown_mean = -10.1%` 说明在当前回测里，收益和风险的关系比较健康。但还不能说它已经稳定可靠，因为还需要继续验证：

1. 完整 Phase 0 对比所有候选策略。
2. 成本敏感性测试，看滑点变大后是否还有效。
3. 分年度表现，看是不是只靠某一年行情。
4. 样本外表现，看参数不是过拟合。
5. 实盘模拟一段时间，看信号和真实成交是否一致。

判断：它已经从“实验策略”进入“值得重点验证的主策略候选”阶段，但还没有到可以无脑执行的程度。
