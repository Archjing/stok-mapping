# 公司财务质量评估方法原文备忘

这属于**基本面财务质量评估**，重点不是直接算“合理股价”，而是判断：

```text
这家公司财务是否健康？
盈利质量如何？
估值贵不贵？
在行业里强不强？
```

常用框架可以分成四层。

**1. 市值与规模定位**

先看公司在行业里的体量：

```text
总市值
流通市值
营收规模
净利润规模
总资产规模
```

作用是判断它是龙头、二线、成长型小公司，还是边缘公司。  
同样的 PE，龙头和小公司的含义可能完全不同。

**2. 财务比率分析**

核心看几组指标：

```text
盈利能力：ROE、ROA、毛利率、净利率
成长能力：营收增速、净利润增速、经营现金流增速
偿债能力：资产负债率、流动比率、速动比率、利息保障倍数
运营效率：存货周转率、应收账款周转率、总资产周转率
现金流质量：经营现金流 / 净利润、自由现金流、资本开支压力
估值水平：PE、PB、PS、EV/EBITDA、股息率
```

作用是把公司拆成：

```text
赚不赚钱
增长快不快
债务重不重
现金流真不真
资产用得好不好
价格贵不贵
```

**3. 行业基准比较**

单看一个公司的指标不够，必须和行业平均或中位数比较。

例如：

```text
公司 ROE 15%
行业中位数 8%
```

说明它盈利能力可能较强。

但如果：

```text
公司资产负债率 70%
行业中位数 75%
```

在某些重资产行业里反而不算高。

所以行业基准的作用是避免误判，因为不同行业天然财务结构不同。

**4. 竞争对手对比**

最后看公司相对同业竞争对手的位置：

```text
市占率
收入增速
利润率
ROE
现金流质量
负债水平
估值倍数
研发投入
分红能力
```

常见判断方式是做一张同业横向表：

```text
公司 | 市值 | PE | PB | ROE | 毛利率 | 净利率 | 营收增速 | 净利增速 | 资产负债率 | 经营现金流/净利润
```

然后判断：

```text
高 ROE + 高增长 + 合理估值 = 优质成长
高 ROE + 低增长 + 高分红 = 稳定价值
低 ROE + 高负债 + 高估值 = 风险偏高
低估值 + 财务改善 + 行业回暖 = 可能反转
```

放到本项目里，这类方法可以作为后续的**基本面质量过滤层**：

```text
动量信号：发现市场正在关注谁
财务质量：判断这家公司底子好不好
行业比较：判断它是不是真的优于同业
估值水平：判断当前价格是否过热
```

未来可以形成类似标签：

```text
动量强势 + 财务优质 + 估值合理 = 优先观察
动量强势 + 财务偏弱 + 高估值 = 谨慎观察
动量转弱 + 财务优质 = 暂不轻易剔除
动量转弱 + 财务恶化 = 降级或剔除
```
