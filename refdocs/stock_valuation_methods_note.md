# 股票估值方法原文备忘

可以，这些属于**基本面估值模型**，主要用于回答：

```text
一只股票大概值多少钱？
当前价格是高估、低估，还是合理？
```

你提到的三类方法含义如下。

**1. 折现现金流 DCF**

DCF 估值是把公司未来能产生的自由现金流折现到今天。

核心逻辑：

```text
公司价值 = 未来自由现金流的现值之和
```

适合：

- 现金流相对稳定的公司
- 成熟行业
- 可以较合理预测收入、利润率、资本开支的公司

缺点：

- 对增长率、折现率、永续增长率非常敏感
- 稍微改一个参数，估值结果可能差很多

**2. 同类公司估值倍数**

也叫相对估值，比如：

```text
PE = 市值 / 净利润
PB = 市值 / 净资产
PS = 市值 / 营收
EV/EBITDA = 企业价值 / EBITDA
```

核心逻辑：

```text
类似公司应该享有相近估值倍数
```

例如：

```text
目标公司合理市值 = 目标公司净利润 × 可比公司平均 PE
```

适合：

- 快速横向比较
- 行业公司较多、商业模式相似
- 市场定价比较充分的行业

缺点：

- 可比公司不一定真正可比
- 整个行业都高估时，相对估值也会偏高
- 周期股、亏损股、成长股容易失真

**3. 股息贴现模型 DDM**

DDM 是把未来股息折现到今天。

核心逻辑：

```text
股票价值 = 未来股息的现值之和
```

常见简化形式：

```text
合理股价 = 下一期股息 / (股权要求回报率 - 股息增长率)
```

适合：

- 高分红公司
- 银行、公用事业、成熟消费等稳定派息企业
- 股息政策清晰的公司

缺点：

- 不分红或低分红成长股不适合
- 对股息增长率和折现率敏感
- 股息政策变化会影响估值稳定性

放到本项目里，它们的作用不是直接替代当前动量策略，而是可以作为后续的**估值过滤层**或**安全边际解释层**：

```text
技术/动量信号：决定观察谁
基本面估值：判断贵不贵
风险/执行约束：判断能不能做
```

例如以后可以形成这样的判断：

```text
动量强势 + 估值合理 = 优先观察
动量强势 + 明显高估 = 降级观察
动量转弱 + 估值低估 = 不立即追卖，进入复核
动量弱势 + 高估 = 剔除或减仓
```
