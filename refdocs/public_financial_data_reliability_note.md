# 公开披露财务数据可信度原文备忘

不能“完全相信”，但也不能简单认为“不可信”。更准确的判断是：

```text
公开披露财务数据是最基础、最正式的数据源，但需要交叉验证、口径理解和异常识别。
```

这些指标的风险主要来自几类。

**1. 会计口径不等于经济真实**

财报按会计准则编制，但会计利润不一定等于真实现金赚钱能力。

例如：

```text
净利润很好，但经营现金流很差
营收增长很快，但应收账款暴增
毛利率稳定，但存货大量增加
```

这类情况说明利润可能还没真正变成现金。

**2. 指标可能被一次性因素扭曲**

PE、ROE、净利增速这些指标容易被非经常性损益影响。

例如：

```text
卖资产导致净利润暴增
政府补助抬高利润
资产减值导致利润骤降
汇兑收益或投资收益影响当期利润
```

所以不能只看单年指标，要看扣非净利润、经营现金流和多年趋势。

**3. 公司可能有盈余管理**

合法范围内，公司可以通过收入确认、费用资本化、减值计提、折旧摊销等方式影响利润节奏。

常见警讯：

```text
营收增长明显快于现金流
应收账款增速明显快于营收
存货增速明显快于销售
利润增长但现金流长期偏弱
毛利率突然大幅高于同行
```

**4. 行业口径差异很大**

同一个指标在不同行业意义不同。

例如：

```text
资产负债率 70%
```

对地产、银行、公用事业可能正常；对轻资产软件公司可能偏高。

所以必须和行业中位数、直接竞争对手比较。

**5. 数据供应商可能有映射和更新错误**

Tushare、Wind、Choice、同花顺、东方财富等数据源通常来自公开披露加工，但加工过程可能出现：

```text
字段口径差异
复权/调整口径差异
行业分类差异
单位错误
更新延迟
历史修订未同步
```

所以重要结论最好回看公告原文或至少多源比对。

在本项目里，我建议把这些数据分成三个可信层级：

```text
一级：交易所公告 / 年报 / 季报原文
二级：Tushare 等结构化财务数据
三级：由结构化数据计算出的衍生指标和评分
```

实际使用时不要问“能不能完全相信”，而是应该做数据质量规则：

```text
净利润增长但经营现金流长期为负 -> 降权
应收账款增速远高于营收增速 -> 风险标记
毛利率突然偏离行业过大 -> 人工复核
PE 极低但利润来自一次性收益 -> 不直接判定低估
ROE 高但资产负债率和财务费用过高 -> 风险标记
```

所以结论是：

```text
公开披露数据可以作为量化系统的基础输入，但不能直接等同于公司真实质量。必须结合现金流、扣非利润、行业比较、异常检测和必要的公告复核。
```
