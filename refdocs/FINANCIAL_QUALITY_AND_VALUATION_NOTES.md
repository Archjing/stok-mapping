# 公司财务质量评估方法原文备忘

这属于**基本面财务质量评估**，重点不是直接算“合理股价”，而是判断：

```text
这家公司财务是否健康？
盈利质量如何？
估值贵不贵？
在行业里强不强？
```

常用框架可以分成四层。

**1. 市值与规模定位**

先看公司在行业里的体量：

```text
总市值
流通市值
营收规模
净利润规模
总资产规模
```

作用是判断它是龙头、二线、成长型小公司，还是边缘公司。  
同样的 PE，龙头和小公司的含义可能完全不同。

**2. 财务比率分析**

核心看几组指标：

```text
盈利能力：ROE、ROA、毛利率、净利率
成长能力：营收增速、净利润增速、经营现金流增速
偿债能力：资产负债率、流动比率、速动比率、利息保障倍数
运营效率：存货周转率、应收账款周转率、总资产周转率
现金流质量：经营现金流 / 净利润、自由现金流、资本开支压力
估值水平：PE、PB、PS、EV/EBITDA、股息率
```

作用是把公司拆成：

```text
赚不赚钱
增长快不快
债务重不重
现金流真不真
资产用得好不好
价格贵不贵
```

**3. 行业基准比较**

单看一个公司的指标不够，必须和行业平均或中位数比较。

例如：

```text
公司 ROE 15%
行业中位数 8%
```

说明它盈利能力可能较强。

但如果：

```text
公司资产负债率 70%
行业中位数 75%
```

在某些重资产行业里反而不算高。

所以行业基准的作用是避免误判，因为不同行业天然财务结构不同。

**4. 竞争对手对比**

最后看公司相对同业竞争对手的位置：

```text
市占率
收入增速
利润率
ROE
现金流质量
负债水平
估值倍数
研发投入
分红能力
```

常见判断方式是做一张同业横向表：

```text
公司 | 市值 | PE | PB | ROE | 毛利率 | 净利率 | 营收增速 | 净利增速 | 资产负债率 | 经营现金流/净利润
```

然后判断：

```text
高 ROE + 高增长 + 合理估值 = 优质成长
高 ROE + 低增长 + 高分红 = 稳定价值
低 ROE + 高负债 + 高估值 = 风险偏高
低估值 + 财务改善 + 行业回暖 = 可能反转
```

放到本项目里，这类方法可以作为后续的**基本面质量过滤层**：

```text
动量信号：发现市场正在关注谁
财务质量：判断这家公司底子好不好
行业比较：判断它是不是真的优于同业
估值水平：判断当前价格是否过热
```

未来可以形成类似标签：

```text
动量强势 + 财务优质 + 估值合理 = 优先观察
动量强势 + 财务偏弱 + 高估值 = 谨慎观察
动量转弱 + 财务优质 = 暂不轻易剔除
动量转弱 + 财务恶化 = 降级或剔除
```

# 公开披露财务数据可信度原文备忘

不能“完全相信”，但也不能简单认为“不可信”。更准确的判断是：

```text
公开披露财务数据是最基础、最正式的数据源，但需要交叉验证、口径理解和异常识别。
```

这些指标的风险主要来自几类。

**1. 会计口径不等于经济真实**

财报按会计准则编制，但会计利润不一定等于真实现金赚钱能力。

例如：

```text
净利润很好，但经营现金流很差
营收增长很快，但应收账款暴增
毛利率稳定，但存货大量增加
```

这类情况说明利润可能还没真正变成现金。

**2. 指标可能被一次性因素扭曲**

PE、ROE、净利增速这些指标容易被非经常性损益影响。

例如：

```text
卖资产导致净利润暴增
政府补助抬高利润
资产减值导致利润骤降
汇兑收益或投资收益影响当期利润
```

所以不能只看单年指标，要看扣非净利润、经营现金流和多年趋势。

**3. 公司可能有盈余管理**

合法范围内，公司可以通过收入确认、费用资本化、减值计提、折旧摊销等方式影响利润节奏。

常见警讯：

```text
营收增长明显快于现金流
应收账款增速明显快于营收
存货增速明显快于销售
利润增长但现金流长期偏弱
毛利率突然大幅高于同行
```

**4. 行业口径差异很大**

同一个指标在不同行业意义不同。

例如：

```text
资产负债率 70%
```

对地产、银行、公用事业可能正常；对轻资产软件公司可能偏高。

所以必须和行业中位数、直接竞争对手比较。

**5. 数据供应商可能有映射和更新错误**

Tushare、Wind、Choice、同花顺、东方财富等数据源通常来自公开披露加工，但加工过程可能出现：

```text
字段口径差异
复权/调整口径差异
行业分类差异
单位错误
更新延迟
历史修订未同步
```

所以重要结论最好回看公告原文或至少多源比对。

在本项目里，我建议把这些数据分成三个可信层级：

```text
一级：交易所公告 / 年报 / 季报原文
二级：Tushare 等结构化财务数据
三级：由结构化数据计算出的衍生指标和评分
```

实际使用时不要问“能不能完全相信”，而是应该做数据质量规则：

```text
净利润增长但经营现金流长期为负 -> 降权
应收账款增速远高于营收增速 -> 风险标记
毛利率突然偏离行业过大 -> 人工复核
PE 极低但利润来自一次性收益 -> 不直接判定低估
ROE 高但资产负债率和财务费用过高 -> 风险标记
```

所以结论是：

```text
公开披露数据可以作为量化系统的基础输入，但不能直接等同于公司真实质量。必须结合现金流、扣非利润、行业比较、异常检测和必要的公告复核。
```

# 股票估值方法原文备忘

可以，这些属于**基本面估值模型**，主要用于回答：

```text
一只股票大概值多少钱？
当前价格是高估、低估，还是合理？
```

你提到的三类方法含义如下。

**1. 折现现金流 DCF**

DCF 估值是把公司未来能产生的自由现金流折现到今天。

核心逻辑：

```text
公司价值 = 未来自由现金流的现值之和
```

适合：

- 现金流相对稳定的公司
- 成熟行业
- 可以较合理预测收入、利润率、资本开支的公司

缺点：

- 对增长率、折现率、永续增长率非常敏感
- 稍微改一个参数，估值结果可能差很多

**2. 同类公司估值倍数**

也叫相对估值，比如：

```text
PE = 市值 / 净利润
PB = 市值 / 净资产
PS = 市值 / 营收
EV/EBITDA = 企业价值 / EBITDA
```

核心逻辑：

```text
类似公司应该享有相近估值倍数
```

例如：

```text
目标公司合理市值 = 目标公司净利润 × 可比公司平均 PE
```

适合：

- 快速横向比较
- 行业公司较多、商业模式相似
- 市场定价比较充分的行业

缺点：

- 可比公司不一定真正可比
- 整个行业都高估时，相对估值也会偏高
- 周期股、亏损股、成长股容易失真

**3. 股息贴现模型 DDM**

DDM 是把未来股息折现到今天。

核心逻辑：

```text
股票价值 = 未来股息的现值之和
```

常见简化形式：

```text
合理股价 = 下一期股息 / (股权要求回报率 - 股息增长率)
```

适合：

- 高分红公司
- 银行、公用事业、成熟消费等稳定派息企业
- 股息政策清晰的公司

缺点：

- 不分红或低分红成长股不适合
- 对股息增长率和折现率敏感
- 股息政策变化会影响估值稳定性

放到本项目里，它们的作用不是直接替代当前动量策略，而是可以作为后续的**估值过滤层**或**安全边际解释层**：

```text
技术/动量信号：决定观察谁
基本面估值：判断贵不贵
风险/执行约束：判断能不能做
```

例如以后可以形成这样的判断：

```text
动量强势 + 估值合理 = 优先观察
动量强势 + 明显高估 = 降级观察
动量转弱 + 估值低估 = 不立即追卖，进入复核
动量弱势 + 高估 = 剔除或减仓
```
