# 真实账户对账 CSV 预留格式

本文件定义账户级仿真 v2 之后预留的本地对账输入格式。当前模块只用于研究复盘和模拟对账，不接券商 API，不自动下单，不生成任何实盘交易指令。

## 1. 真实持仓 CSV

建议路径由本地配置或命令行传入，不纳入 Git。项目内仅保留字段定义。

| 字段 | 含义 | 示例 |
|------|------|------|
| `account_id` | 本地账户标识，可脱敏 | `paper_cn_01` |
| `as_of_date` | 持仓日期 | `2026-05-29` |
| `symbol` | 股票代码，沿用项目格式 | `SH.600519` |
| `stock_name` | 股票名称 | `贵州茅台` |
| `total_qty` | 总持仓股数 | `100` |
| `available_qty` | 可卖股数 | `100` |
| `cost_price` | 持仓成本价 | `1500.00` |
| `market_price` | 当日或券商显示市价 | `1520.00` |
| `market_value` | 市值 | `152000.00` |

## 2. 券商成交回报 CSV

| 字段 | 含义 | 示例 |
|------|------|------|
| `account_id` | 本地账户标识，可脱敏 | `paper_cn_01` |
| `trade_datetime` | 成交日期时间 | `2026-05-29 09:35:12` |
| `symbol` | 股票代码，沿用项目格式 | `SH.600519` |
| `stock_name` | 股票名称 | `贵州茅台` |
| `side` | 买卖方向：`买` / `卖` | `买` |
| `filled_qty` | 实际成交股数 | `100` |
| `filled_price` | 实际成交价 | `1520.00` |
| `filled_amount` | 实际成交金额 | `152000.00` |
| `fee` | 佣金、印花税等费用合计 | `418.00` |
| `order_id` | 券商委托号，可为空 | `A202605290001` |

## 3. 后续对账输出

后续实现对账时，至少输出两张差异表：

- 模拟持仓 vs 真实持仓：比较 `symbol`、持仓股数、市值、权重和现金差异。
- 模拟成交 vs 真实成交：比较交易日期、买卖方向、成交股数、成交价、成交金额和交易费用差异。

## 4. 边界

- 真实账户文件必须存放在 `.env` 指定的本地私有路径或命令行传入路径，不提交到仓库。
- 该模块只做事后复盘，不对外发送订单。
- 若真实账户代码格式与项目格式不同，先在导入层转换为 `SH.600000` / `SZ.000001` 这类统一格式。
