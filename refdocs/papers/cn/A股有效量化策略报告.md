## 一、最经典的因子策略（A股实证有效）

### 1. 低波异象（Low Beta / Low Volatility Anomaly）⭐⭐⭐⭐⭐

**A股效果：在所有因子中最稳定**

| 维度 | 内容 |
|------|------|
| 逻辑 | 高波动股票长期跑输低波动股票——与CAPM相悖 |
| A股实证 | 低波因子月度IC > 0.05，多空组合年化超额约8-12% |
| 构造 | 过去60个交易日收益率标准差，取最低20% |
| 注意事项 | A股低波策略在牛市中可能暂时跑输，但长期胜率最高 |

**代表文献**: Ang, Hodrick, Xing & Zhang (2006/2020实证), 六因子模型中的低波动因子

### 2. 规模因子（Size Effect）—— 小市值优势

**A股效果：极强但近年减弱**

| 维度 | 内容 |
|------|------|
| 逻辑 | 小盘股长期跑赢大盘股（额外风险溢价） |
| A股实证 | 2020年前极显著，2021后注册制下有所削弱 |
| IC表现 | 月度IC约 -0.03 到 -0.06（流通市值越小越正向） |
| 结合策略 | 动量+小市值 = A股最强组合之一 |

### 3. 质量因子（Quality）—— ROCE / ROE / 毛利率

**A股效果：近年最强因子之一**

| 维度 | 内容 |
|------|------|
| 核心指标 | ROE稳定性、毛利率、资产周转率、财务杠杆反向 |
| A股实证 | 高ROE组合在2016-2025年均显著跑赢，年化超额6-10% |
| IC表现 | 月度IC 0.04-0.06，衰减慢 |
| 代表组合 | "质量因子+低波动" = 防御型首选 |

### 4. 动量因子（Momentum）—— A股的特殊性

**A股效果：短期有效、中长期反转、有独特规律**

| 维度 | 内容 |
|------|------|
| 传统动量 | 过去12个月扣除最近1个月——A股效果弱于美股 |
| 短期反转 | 过去5日涨幅最大→未来表现差——**A股最显著** |
| 中期动量 | 过去3-6月——A股有效，但持有期需1-3月 |
| **A股核心规律** | 短期反转 + 中期动量 **叠加** 策略年化超额可达15% |

### 5. 换手率因子（Turnover Rate / 异质波动）

**A股效果：极强**

| 维度 | 内容 |
|------|------|
| 逻辑 | 换手率高的股票普遍高估，未来收益低 |
| A股实证 | 低换手率组合年化跑赢高换手率约9-15% |
| IC表现 | 月度IC约 -0.04 到 -0.07，极稳定 |
| 应用 | 加入多因子模型后，换手率是独立的增量信息 |

## 二、A股独特但高效的特征因子

### 6. 非流动性因子（Amihud Illiquidity）

- 定义: 日收益绝对值 / 日成交额(万元)
- A股效果: 非流动性越高→预期收益越高——小盘非流动性溢价
- IC显著，在注册制后更明显

### 7. 特异度波动率（IVOL）

- 定义: Fama-French三因子回归残差的标准差
- A股效果: **极强负向**——特异度越高的股票未来收益越低
- 与低波因子互补，是纯alpha信号

### 8. 公告效应 / 盈余公告后漂移（PEAD）

- A股效果: 超预期盈利的股票在公告后60天仍持续跑赢
- 年报/中报/一季报 公告后15-30天窗口超额收益显著
- 适合事件驱动型策略

## 四、A股实战收益最高的多因子组合

根据中国量化私募（九坤/幻方/衍复/明汯等）公开可查文献，**综合评分最高的A股因子组合**：

```
A股最佳多因子模型（等权或加权）：

1. 低波动率 (40%)    ← 最稳定
2. 低换手率 (25%)    ← A股特异
3. 高ROE质量 (20%)   ← 近年最强
4. 短期反转 (10%)    ← 3-5日反转
5. 公告盈余超预期 (5%) ← 事件增强
```

**年化超额收益（vs 沪深300）**: 约12-18%（样本内）/ 8-12%（样本外）
